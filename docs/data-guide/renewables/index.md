# Renewable Electricity

The renewable workflow converts Canadian weather and land evidence into
regional wind and solar investment options for Gold.

It combines three distinct evidence roles:

- ERA5 provides hourly weather;
- NREL reference turbine curves and Atlite provide physical conversion; and
- ATB provides selected technology costs and representative class mappings.

Land-cover and protected-area sources determine eligible area. Configured
deployment densities convert that area into capacity bounds. Gold replaces the
legacy electricity-generation representation only when the selected renewable
bundle covers every model node and passes its checksum and contract validation.
