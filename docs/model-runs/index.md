# Model Development Records

Model-development records preserve why a representation changed, not merely
what changed in code or configuration.

## Structural sensitivity runs

[Structural sensitivity runs](structural-sensitivity/index.md) compare
alternative model structures such as resource mappings, transport options or
cost representations.

## Decision records

[Decision records](decision-records/index.md) capture the conclusion drawn from
one or more experiments and the consequences for the maintained model.

Generated databases, solver logs, plots and large validation products remain in
their normal local output directories. Records should cite stable manifest or
run identities when available.
