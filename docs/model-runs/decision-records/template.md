# Decision: concise title

- **Status:** proposed, accepted, superseded, or rejected
- **Date:** YYYY-MM-DD
- **Related sensitivity:** link to the run record
- **Affected configuration/code:** paths

## Context

What model behaviour, evidence gap or representational problem required a
decision?

## Alternatives considered

List the credible alternatives and the reason each was evaluated or excluded.

## Evidence

Record the comparison design, stable run/manifest identities, important
diagnostics and the result that informed the decision. Keep generated artifacts
in their normal local output directories.

## Decision

State the chosen model representation precisely.

## Consequences

Describe improvements, tradeoffs, limitations, required follow-up work and
conditions that would cause the decision to be revisited.
