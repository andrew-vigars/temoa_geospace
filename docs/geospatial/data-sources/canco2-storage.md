## How to update

Produced by the `canco2-storage` repository. Build a new release there, then run `python -m geocanoe.acquisition.co2_storage` (or `geocanoe-build-bronze --stages co2_storage`), using `CANCO2_STORAGE_REPO` or `CANCO2_STORAGE_GPKG` to select the source. The newest timestamped GeoPackage is chosen by default and recorded in `selected_release.txt`. Rebuild the storage mapping and Gold.

See also [update procedures](update-procedures.md).
