# 2. 2020 Land Cover of Canada

> Generated by `docs/tools/gen_sources.py`. Do not edit by hand.

## Description

National 2020 land-cover classification used to exclude water, wetlands, built-up land and, for solar, cropland from renewable deployment areas. Bronze preserves the original raster; renewable Silver performs the configured masking and area accounting.

## Notes
