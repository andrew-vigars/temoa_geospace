# 6. 2021 Census provincial and territorial boundaries

> Generated by `docs/tools/gen_sources.py`. Do not edit by hand.

## Description

Generalized provincial and territorial boundary polygons from the 2021 Census. They define the study area (dissolved selected jurisdictions), the province attribute of legacy site points, and the province of each basemap cell.

- **Registry ID:** `statcan_2021_province_territory_boundaries`
- **Publisher:** Statistics Canada
- **Licence:** Statistics Canada Open Licence
- **Domain / kind:** administrative_boundaries / vector_dataset

## How to update

The release is fixed (2021 Census), so routine updates are not expected. A new census release would need a new registry entry, a check of the province-name column and code mapping, and a rebuild of every Silver product, since region IDs depend on the boundary.

See also [update procedures](update-procedures.md).
