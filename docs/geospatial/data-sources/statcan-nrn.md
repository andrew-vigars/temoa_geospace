> Generated by `docs/tools/gen_sources.py`. Do not edit by hand.

## Description

National Road Network (NRN), distributed as one GeoPackage per province or territory. Provides road segments classified by function; used to decide which graph edges may carry trucks.

- **Registry ID:** `statcan_nrn_national_bilingual`
- **Publisher:** Statistics Canada
- **Licence:** Statistics Canada Open Licence
- **Domain / kind:** transportation / vector_database_collection

## How to update

Rolling jurisdictional releases. The `nrn` Bronze stage downloads every province and territory, so adding a jurisdiction to the study area needs no new acquisition. To refresh, re-run it with `--overwrite`, note the NRN edition from the file names, then rebuild roads, connectivity, and Gold.

See also [update procedures](update-procedures.md).
