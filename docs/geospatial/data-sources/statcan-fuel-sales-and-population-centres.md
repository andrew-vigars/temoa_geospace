## How to update

The sales table is a rolling annual release. To move to a new year, re-run the `gasoline_demand` Bronze stage with `--overwrite`, set `[gasoline_demand].sales_year` in the build profile (the build fails if that year or a jurisdiction is missing), and rebuild Silver gasoline demand and Gold. Population-centre geography is fixed at 2021.

See also [update procedures](update-procedures.md).
